# Reproducible environment

This repository is currently a theory/documentation bootstrap; no numerical production calculation has been run here. No Python, Mathematica, compiler, BLAS, or hardware version is invented in the initial manifest.

Before the first production run, pin Python and dependency lock, Mathematica/Wolfram Engine version, OS/architecture, CPU/RAM/GPU, BLAS/LAPACK, environment variables, precision, and thread counts. Use the local research environment for production; GitHub Actions is an independent reproduction/regression check.
