# Research Task Handoff Standard

Use the central [Research Task Handoff Standard](https://github.com/lm846802297-bit/high-energy-theory-research/blob/14155487afc075d301fa7f6cf452c7bff137e869/docs/RESEARCH_TASK_HANDOFF_STANDARD.md) and its [task brief template](https://github.com/lm846802297-bit/high-energy-theory-research/blob/14155487afc075d301fa7f6cf452c7bff137e869/templates/research-task-brief.md), pinned to central commit `14155487afc075d301fa7f6cf452c7bff137e869`.

For substantive work, create a task brief before execution. Record the exact baseline commit, primary literature/data sources, conventions, assumptions, previously validated results, independent derivations, and predeclared acceptance criteria. For numerical runs, repeat task-level standards provenance in `run_manifest.extensions.standards_provenance`.

Use the project's existing `docs/task_briefs/` location for completed briefs; do not reconstruct task specifications from chat history.
