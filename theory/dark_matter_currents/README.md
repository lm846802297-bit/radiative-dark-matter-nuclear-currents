# Dark-matter transition currents and radiation kernels

For neutral scalar emission \(\Gamma_s=1\), the two coherent radiation orderings are

\[
\mathcal T_X^{\alpha_X}=
\bar u_{\chi_1}(p_\chi')
\left[
\Gamma_{\chi X}^{\alpha_X}S_2(p_\chi-k_s)\Gamma_s+
\Gamma_sS_2(p_\chi'+k_s)\Gamma_{\chi X}^{\alpha_X}
\right]u_{\chi_1}(p_\chi).
\]

Sum both terms before squaring. \(S_2\) is the complete intermediate-\(\chi_2\) propagator with the declared width prescription.

The first channel letter labels the dark-matter transition bilinear; the second labels the nucleon source:

| Channel | Dark bilinear | Nucleon source |
|---|---|---|
| VV | \(\bar\chi_2\gamma^\mu\chi_1\) | \(J_V^\mu\) |
| VA | \(\bar\chi_2\gamma^\mu\chi_1\) | \(J_A^\mu\) |
| AV | \(\bar\chi_2\gamma^\mu\gamma_5\chi_1\) | \(J_V^\mu\) |
| AA | \(\bar\chi_2\gamma^\mu\gamma_5\chi_1\) | \(J_A^\mu\) |
| SS | \(\bar\chi_2\chi_1\) | \(J_S\) |

For SS, the dark scattering and scalar-emission vertices are scalar; its kernel is not the vector/axial \(L_{\mu\nu}^{(3)}\) tensor. Each channel requires its own direct-amplitude and integrated-kernel checks.
