# Chiral-EFT nuclear forces and currents

Nuclear currents and nuclear states must be defined in a mutually consistent chiral-EFT scheme. Pin the chiral order, regulator/cutoff, NN and 3N interaction, fitted LECs, many-body method/model space, one-/two-body current operators, operator evolution, and matching scale.

The presence and order of two-body currents depend on both the dark-matter-side bilinear and the nucleon-side source. Hoferichter, Klos, and Schwenk (2015) find that the only two-body vector current through \(\mathcal O(p^3)\) is in the AV channel; it is not a VV contribution. This is an order-limited result, not an all-orders absence theorem. Electromagnetic isoscalar exchange currents and their LECs are not automatically the current for a flavor-universal dark-matter baryon-number source; re-match the external source before using them.

Check vector continuity or axial PCAC using the selected Hamiltonian/current pair. Keep chiral truncation, regulator, and many-body uncertainties separate.
