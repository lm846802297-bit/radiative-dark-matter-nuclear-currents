# Xenon nuclear inputs

The inherited AFH response set covers \(^{128,129,130,131,132,134,136}\mathrm{Xe}\). Its seven-isotope atom-fraction coverage is 99.8158% in the inherited baseline; the omitted \(^{124}\mathrm{Xe}\) and \(^{126}\mathrm{Xe}\) fractions must remain explicit in rate normalization.

For elastic axial spin responses, \(^{129}\mathrm{Xe}\) and \(^{131}\mathrm{Xe}\) are the primary targets. Even-even isotopes contribute to coherent vector/scalar density responses.

For every isotope, record mass convention, abundance, nuclear spin, oscillator length, nuclear Hamiltonian/model, OBDME or structure-factor source, and q-grid.
